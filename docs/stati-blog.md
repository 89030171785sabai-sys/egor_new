# Статьи блога (129 шт.)

Статьи лежат в репозитории как готовые файлы, а не в базе:

- список (заголовок, описание, рубрика, время чтения) — `src/data/articles.generated.ts`;
- тексты со схемами и таблицами — `src/content/articles/<адрес>.html`
  (открываются отдельным файлом только на странице самой статьи);
- фото — `public/blog/<адрес>/hero.webp` (главное), `thumb.webp` (для карточки), `01.webp`… (внутри текста).

Всё это создаёт скрипт из исходных папок «001 тема», «002 тема»…:

    python3 scripts/import-articles.py "<папка с распакованными статьями>"

Скрипт можно запускать повторно, он перезаписывает результат. Руками перечисленные
файлы не правят: при следующем запуске правки пропадут. Исходные архивы лежат в
корне репозитория (`Статьи хоттаб-чан.рф — часть 0N из 08 …zip`).

У 30 статей (№ 100–129) в исходниках нет главного фото; в списке и на странице
для них подставляется снимок с сайта.
