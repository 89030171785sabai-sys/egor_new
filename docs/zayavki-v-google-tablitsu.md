# Заявки с сайта в Google-таблицу

Сайт отправляет каждую заявку на адрес из секрета `LEADS_ENDPOINT`. Ниже —
как сделать этот адрес из обычной Google-таблицы, без программирования.

## 1. Таблица и скрипт (5 минут)
1. Создайте новую Google-таблицу, назовите «Заявки HOTTUB».
2. Меню **Расширения → Apps Script**.
3. Сотрите всё, что там есть, и вставьте код из файла
   `docs/zayavki-v-google-tablitsu.gs`.
4. Нажмите значок дискеты (сохранить).

## 2. Опубликовать как веб-приложение
1. Справа вверху **Развернуть → Новое развёртывание**.
2. Шестерёнка → тип **Веб-приложение**.
3. «Запускать от имени»: **Я** (ваша почта).
   «У кого есть доступ»: **Все**.
4. **Развернуть**, разрешить доступ (Google спросит про безопасность —
   «Дополнительно → Перейти»). Скрипт пишет только в эту таблицу.
5. Скопируйте **URL веб-приложения** — он начинается с
   `https://script.google.com/macros/s/…/exec`.

## 3. Подключить к сайту
GitHub → репозиторий → Settings → Secrets and variables → Actions →
New repository secret: имя `LEADS_ENDPOINT`, значение — тот URL.
После этого любая публикация сайта (или кнопка «Run workflow») включит приём.

## Проверка
Отправьте заявку с сайта — в таблице появится лист «Заявки» и строка.

## Важно знать
- **Персональные данные.** Имя и телефон хранятся в сервисе Google. По закону
  (152-ФЗ) данные россиян нужно хранить на серверах в России. Для сайта
  с реальным потоком заявок это риск; безопаснее Яндекс Формы, Битрикс24,
  amoCRM или Telegram-бот. Решение за вами и вашим юристом. В политике
  конфиденциальности тогда нужно добавить Google как получателя данных.
- **Спам.** Адрес скрипта виден в коде сайта, и кто-то может слать на него
  мусор. Если начнётся — добавим защиту (скрытое поле, ограничение частоты).
- **Подтверждения нет.** Сайт не видит ответа Google, поэтому показывает
  «отправлено», даже если скрипт сломался. Раз в день заглядывайте в таблицу
  или попросите добавить уведомление на почту.
- Если вы позже поменяете код скрипта, нужно снова «Развернуть → Управление
  развёртываниями → Изменить → Новая версия», иначе сайт получит старую версию.
