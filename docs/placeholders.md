# Заглушки, которые ждут замены

Ни одной настоящей фотографии на сайте пока нет — везде стоят
процедурные заглушки. Компонент `PlaceholderImage` держит пропорции,
композицию и подпись слота, поэтому вёрстку можно оценивать уже сейчас,
но перед публикацией всё перечисленное надо заменить.

## Как заменить

1. Положить снимок в `public/photos/` (или подключить CDN).
2. В нужном месте заменить `<PlaceholderImage … />` на `<img>` с теми же
   пропорциями и осмысленным `alt`.
3. Убрать `PlaceholderNote` из `src/components/ui/PageHeader.tsx` — этот
   компонент рисует оранжевую плашку «Заглушка вместо фотографии» и
   существует только затем, чтобы о подмене нельзя было забыть.

## Что именно нужно снять

### Шапки внутренних страниц
Каждая помечена на самой странице оранжевой плашкой с описанием кадра.

| Страница | Нужный кадр |
| --- | --- |
| `/catalog` | Несколько чанов линейки на площадке |
| `/production` | Сварка чаши в цеху |
| `/delivery` | Погрузка чана в машину на площадке |
| `/guarantees` | Сварной шов чаши крупным планом |
| `/faq` | Чан с паром на участке зимой |
| `/contacts` | Площадка производства снаружи |

### Главная страница

- Hero — чан на участке в вечернем свете, горизонтальный кадр
- Слайдер моделей — по одному лайфстайл-кадру на каждую из 6 моделей
- Bento-сетка «про отдых» — живой огонь в топке, чан зимой у дома,
  печь с дровами, фактура нержавеющей стали
- Блок кастомизации — 4 кадра под пункты аккордеона: цвет, размер,
  отделка, дополнительные опции
- Карта доставки — либо реальная карта, либо векторный контур России

### Каталог и страницы моделей

- Товарное фото на светлом фоне для каждой из 6 моделей
- Вид изнутри чаши для каждой модели
- Печь и дымоход крупным планом для каждой модели
