# Яндекс Метрика и Вебмастер

Всё, что можно сделать в коде, уже сделано. От вас нужны три номера/кода из
кабинетов Яндекса. Пароли и доступы никому не присылайте — только то, что
написано ниже.

## 1. Яндекс Метрика (5 минут)
1. metrika.yandex.ru → **Добавить счётчик**.
2. Название: «HOTTUB», адрес сайта: `хоттаб-чан.рф`. Включите «Вебвизор,
   карта кликов, аналитика форм» (код сайта это уже запрашивает).
3. Нажмите **Создать счётчик**. Яндекс покажет **номер счётчика** (8 цифр) —
   его и нужно мне прислать (он не секретный). Код-вставку копировать не нужно.
4. Цели (Настройка → Цели → Добавить цель → «JavaScript-событие»):
   - название «Заявка», идентификатор цели `lead`.
   Тогда каждая отправленная форма будет считаться заявкой.

Как работает счётчик: он включается только после того, как посетитель принял
уведомление о cookie. Пока не нажали «Принять», он ничего не собирает — так
написано в политике конфиденциальности.

Номер счётчика кладётся в GitHub: Settings → Secrets and variables → Actions →
Secrets → `YANDEX_METRIKA_ID`. Или пришлите его мне, я подскажу, куда.

## 2. Яндекс Вебмастер (10 минут)
1. webmaster.yandex.ru → **Добавить сайт** → `https://хоттаб-чан.рф`.
2. Способ подтверждения прав: **Meta-тег**. Яндекс покажет строку вида
   `<meta name="yandex-verification" content="1234abcd5678" />`.
   Нужен только код из `content="…"`.
3. GitHub → Settings → Secrets and variables → Actions → вкладка **Variables** →
   New repository variable: имя `YANDEX_VERIFICATION`, значение — код.
   (Это не секрет, поэтому именно Variables.) Затем запустите публикацию:
   Actions → «Публикация на reg.ru по FTP» → Run workflow.
4. Вернитесь в Вебмастер и нажмите **Проверить**.
5. **Индексирование → Файлы Sitemap** → добавьте
   `https://хоттаб-чан.рф/sitemap.xml`.
6. **Индексирование → Переобход страниц** → отправьте главную и страницы
   моделей.
7. **Настройки → Регион сайта** → задайте «Россия» (или Москва).

Для Google то же самое: search.google.com/search-console → «Префикс URL» →
HTML-тег → код в переменную `GOOGLE_VERIFICATION`.

## Что ждать
- Данные в Метрике появляются через несколько минут после первого визита с
  принятыми cookie.
- Попадание в поиск — от нескольких дней до нескольких недель. Ускоряют
  переобход в Вебмастере и ссылки на сайт из соцсетей и справочников.
